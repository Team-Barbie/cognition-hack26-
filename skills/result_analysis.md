name: result_analysis
revision: 1

Method for interpreting recorded experiment outputs.
- Use only the recorded outputs and hashes in the packet; never restate numbers you were not given.
- A run that exited cleanly is not a scientific success; check that expected outputs exist.
- Note controls, sample size, seeds, and what one run cannot show about uncertainty.
- List failure modes and alternative readings of the numbers.
- A test that was not executed is not a completed test.
