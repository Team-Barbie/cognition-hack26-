Method for a bounded, auditable literature review.
- Plan concept and synonym queries for every subquestion before collecting results.
- Use each enabled index and include searches for null findings, failures, contradictory evidence and replication.
- Preserve the protocol, search strings, filters, cursors, dates, and every exclusion reason.
- Screen on only the metadata or abstract actually supplied. Keep uncertain candidates for acquisition.
- Search snippets are discovery hints, never original-paper passages. Mark abstract-only and web-page reading.
- Follow real reference titles/DOIs and later work through targeted citation queries; never invent references.
- Compare study designs, population/data, baselines, uncertainty, confounding, publication status and scope.
- Distinguish multiple reports of one study and do not vote by publication count.
- Map each subquestion to accepted claim IDs, report contradictory evidence, and identify uncovered questions.
- Request follow-up searches for gaps. Stop at runtime budgets or strategy exhaustion and report why.
- A quote match proves provenance, not scientific validity. No bounded automated search proves exhaustiveness.
